# 可视化导论 · 交互式网页课程

一个面向可视化入门学习的交互式课程网站，通过讲解、参数演示和代码练习，学习如何组织信息、建立页面层级并设计适合不同屏幕的布局。

当前开放 **第一章：Web 页面布局**。课程以“形藏”博物馆专题页为案例，分 6 个小节介绍从内容规划到可用性检查的制作过程，支持中英双语与明暗主题切换。

[访问课程首页](https://could-yun.github.io/visualization-introduction/) · [进入第一章](https://could-yun.github.io/visualization-introduction/lesson-01/)

## 主要功能

- **交互演示**：调整内容顺序、容器宽度、列数、间距、图文比例等参数，实时观察布局变化，并查看对应的 HTML / CSS 示例。
- **在线代码练习**：直接编辑 HTML 或 CSS，在独立预览区域查看结果，支持 720px 和 390px 两种练习预览宽度。
- **练习检查与反馈**：结合页面结构、实际样式和布局尺寸检查练习结果，配套概念题、提示及参考答案。
- **练习结果下载**：将当前练习页面下载为 HTML 文件，便于保存和继续修改。
- **学习进度记录**：完成练习与概念题后记录小节进度，可从首页继续学习。
- **双语与主题切换**：课程内容和交互界面支持中文、英文，以及明暗两种主题。

## 第一章：Web 页面布局

| 小节 | 内容 | 练习重点 |
|---|---|---|
| 01 内容规划 | 明确页面任务，组织信息与阅读顺序 | 调整内容顺序和主要行动按钮 |
| 02 语义结构 | 使用语义化 HTML 建立页面骨架 | 导航、主体与章节结构 |
| 03 容器与网格 | 理解容器、列、间距和对齐关系 | 居中容器与三列卡片布局 |
| 04 模块编排 | 组织首屏、指标与展品的视觉层级 | 图文双栏、间距与标题尺度 |
| 05 响应式布局 | 根据屏幕宽度重排内容 | 桌面双栏与移动端单栏切换 |
| 06 可用性检查 | 检查文字、点击区域与键盘焦点 | 正文字号、按钮尺寸与焦点样式 |

## 使用方式

1. 从课程首页进入第一章，按小节阅读说明并调整演示参数。
2. 在代码练习区编辑 HTML / CSS，观察预览并点击检查结果。
3. 完成练习与概念题后，点击小节完成按钮记录进度，继续下一节。

学习进度、语言和主题偏好保存在当前浏览器中，不提供跨设备同步。练习代码可通过下载功能自行保存。

## 本地运行

项目使用原生 HTML、CSS 和 JavaScript（ES Modules），无需安装前端依赖或执行构建。

安装 Python 3 后，在终端运行：

```bash
git clone https://github.com/Could-Yun/visualization-introduction.git
cd visualization-introduction
python -m http.server 8000
```

在浏览器中打开 [http://localhost:8000/](http://localhost:8000/)，或直接进入 [第一章](http://localhost:8000/lesson-01/)。

请通过本地 HTTP 服务访问，直接双击 HTML 文件可能导致 JavaScript 模块无法正常加载。
